# Addis Market List 
## About
Addis Market List is a simple shopping list website. It helps users add items they need to buy, keep track of prices and quantities, mark items as bought, and see the total cost.
## Features
 -Add an item with its name, price, and quantity.
 -Shows an error when the input is invalid.
 -Mark items as bought.
 -Delete items from the list.
 -Search for items.
 -Filter items by *All, Remaining, or Bought*.
 -Clear bought items or clear the whole list.
 -Shows total items, bought items, and remaining items.
 -Shows the total cost in ETB.
 -Includes a shopping progress ssssbar.
## How It Works
When an item is added, JavaScript stores it in an array and displays it on the page. The user can then buy, delete, search, or filter the items. The statistics and progress bar update automatically whenever the list changes.
